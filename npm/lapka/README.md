# lapka

Lapka, the local anime player, by its short name.

```bash
npx -y lapka
```

This package holds no player of its own: it runs the newest
[@mythhand/lapka](https://www.npmjs.com/package/@mythhand/lapka) and hands it
the terminal. Everything about Lapka, the guide included, is in the repository:
https://github.com/MythHand/Lapka
